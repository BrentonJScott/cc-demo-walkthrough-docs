# Search recipes by name

Narrow the list under **ALL RECIPES** so you only see recipes whose names match what you type.

**Demo URL:** https://demo-angular-22-wgdt.free.ccpve.co.za

## Steps

### Step 1 — Sign in

1. Open the demo URL. You see the **Log in** page.
2. Type any **Email** and **Password**.
3. Click the blue **Log in** link in the white form card.

You land on **Recipe book**.

![Log in page](/assets/guides/search-recipes-by-name/step-1-login.png)

### Step 2 — Open the search field

Under **ALL RECIPES**, click the **Search recipes** field (placeholder: *Search recipes*).

![Recipes page with search field](/assets/guides/search-recipes-by-name/step-2-search-field.png)

### Step 3 — Type a recipe name

Type part of a recipe name, for example `carbon`.

The recipe list shows only matching names (for example **Spaghetti carbonara**). Non-matching recipes are hidden until you clear or change the search text.

![Filtered recipe list](/assets/guides/search-recipes-by-name/step-3-filtered-list.png)

### Step 4 — Clear the search (optional)

Select all text in **Search recipes** and delete it, or backspace until the field is empty.

The full recipe list under **ALL RECIPES** returns.

![Full recipe list after clearing search](/assets/guides/search-recipes-by-name/step-4-full-list.png)
